Atividades de HTML e CSS

Repositório destinado às atividades acadêmicas desenvolvidas durante meus estudos de Engenharia de Software.

O objetivo destes exercícios é praticar os fundamentos do desenvolvimento web utilizando HTML e CSS.

Conteúdos praticados

- Estrutura básica de páginas HTML
- Títulos e parágrafos
- Links internos e externos
- Imagens
- Tabelas
- Colspan e rowspan
- Navegação entre páginas
- Estilização básica com CSS

Tecnologias

- HTML5
- CSS3

Atividades

Atividade 1
Página utilizando elementos básicos de HTML, textos e links.

Atividade 2
Construção de tabela utilizando HTML e aplicação de estilos básicos com CSS.

Atividade 3
Página sobre pontos turísticos de Curitiba utilizando textos, imagens e links externos.
